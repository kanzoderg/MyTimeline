# FADL
Furaffinity downloalder.

```
Furaffinity Downloader

positional arguments:
  url                   URL of the Furaffinity user, post or journal to download

options:
  -h, --help            show this help message and exit
  --proxy PROXY         Proxy URL (e.g., http://127.0.0.1:10808)
  -o, --output OUTPUT   Directory to save downloaded content
  -f, --force           Force fetch all.
  --cookies COOKIES     Cookies for authentication
  --user-agent USER_AGENT
                        Custom User-Agent header
  -ni, --no-interactive
                        Run in non-interactive mode (no progress bars, minimal output)
```
