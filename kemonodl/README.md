# KemonoDL

Kemono.party / Coomer.party downloader.

```
Kemono Downloader

positional arguments:
  url                   URL of the Kemono user or post to download

options:
  -h, --help            show this help message and exit
  --proxy PROXY         Proxy URL (e.g. http://127.0.0.1:8080)
  -o, --output OUTPUT   Directory to save downloaded content
  --skip-files          Skip downloading files, only save JSON data
  --size-limit SIZE_LIMIT
                        Maximum file size to download in MB (default: 1000 MB)
  -ni, --no-interactive
                        Run in non-interactive mode (no progress bars, minimal output)

```
